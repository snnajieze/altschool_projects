## Description

This Weather App was built me using plain HTML, CSS, and JavaScript with no frameworks or external libraries. It fetches live weather data from the [Open-Meteo API](https://open-meteo.com/) (free, no API key required). Users can search for any city in the world to instantly see the current temperature, humidity, wind speed, UV index, and a 5-day forecast. On page load the app also attempts to detect the user's location automatically using the browser's geolocation API and display local weather without any input needed.
